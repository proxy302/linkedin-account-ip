## 先看 LinkedIn 自己的规定

[用户协议](https://www.linkedin.com/legal/user-agreement)（2025 年 11 月 3 日生效）里和这件事有关的三条：

- **一人一个实名账号。** 第 2.1 条：你只能有一个 LinkedIn 账号，并且必须使用真实姓名。
- **不共用账号。** 第 2.2 条：不与任何人共用你的账号；第 8.2 条：不使用、也不尝试使用别人的账号。
- **不用机器人。** 第 8.2 条同样禁止使用机器人和其他未经授权的自动化方式，也禁止用软件、脚本或浏览器插件抓取或自动操作。

这三条说的都是人和行为，不是网络地址。给每个资料页配一条 IP，并不会让第二个账号变得合规，也不会让共用登录、自动化工具变得可以接受。本文只写给想让自己登录保持稳定的真实用户。

## 谁需要固定 IP，谁不需要

| 你的情况 | 要不要固定 IP |
|---|---|
| 在家用宽带或在公司办公室登录 | 不需要，照常用 |
| 经常在联合办公空间、酒店、咖啡馆办公 | 有帮助：那里的公网地址和陌生人共用 |
| 公司的其他全局网络工具把流量从别的国家出去，或者每天出口都不一样 | 有帮助：LinkedIn 固定走一个地址，国家就是你工作的国家 |
| 经常在工作所在的几个国家之间出差 | 有帮助：人在动，登录来源不变 |
| 公司要求员工从一个已知地址访问 LinkedIn | 需要，一人一条；怎么登记由你们自己的管理员决定 |
| 想同时用好几个 LinkedIn 资料页 | IP 解决不了：LinkedIn 只允许一人一个账号 |

## 选哪种 IP

| 方式 | 稳定吗 | 登录 LinkedIn 合不合适 |
|---|---|---|
| 公共的其他全局网络工具出口 | 不稳定，很多人一起用 | 不合适 |
| 动态住宅代理 | 不稳定，本来就会换 | 不合适，适合不登录的数据采集 |
| 机房 IP | 稳定 | 能用，但网站看到的是托管机房网段，不是家庭或办公线路 |
| 静态 ISP IP | 租期内一直不变 | 合适 |

## 配置步骤

1. **给用这个账号的人买一条。** 协议选 HTTP：Chrome 等 Chromium 内核浏览器不支持带账号密码的 SOCKS5。
2. **先在终端查一下**（USER、PASS、HOST、PORT 是占位符）：

   ```bash
   curl -sS -x "http://USER:PASS@HOST:PORT" https://ipinfo.io/json
   ```

   `country` 应是你买的国家，`org` 应是网络运营商，而不是托管机房。
3. **给 LinkedIn 单独开一个浏览器配置**，比如一个单独的 Chrome 用户配置加代理扩展，在里面打开 `https://ipinfo.io/json`，结果应该和上一步一样。
4. **电脑上只在这个配置里登录。** 如果还没开两步验证，在 LinkedIn 的登录与安全设置里打开。
5. **手机上**，LinkedIn App 走手机自己的网络。自己的账号用自己的手机，这很正常；要做到的是电脑上的登录不再在各种网络之间跳。
6. **到期前续费**，或者给这条 IP 打开自动续费。续费还是原来的地址；过期后 IP 被释放，再买就是新地址。

## 团队和公司主页

- **公司主页。** 由超级管理员在主页的管理员设置里添加同事，角色有超级管理员、内容管理员、分析员等。每个人登录自己的资料页，不存在共用密码，也不用安排共用 IP。
- **销售、招聘团队。** 每个人用自己的账号。需要固定 IP 的话，一人一条，国家按各自实际工作的国家。
- **代运营公司。** 替客户发主页内容，走主页管理员角色。登录客户员工的个人资料页就是共用账号，用什么网络都一样。

## 常见问题现象

| 现象 | 可能原因 | 怎么办 |
|---|---|---|
| LinkedIn 老是让你确认登录 | 有时走代理、有时不走，或者两个浏览器都在登录 | 电脑上只用那一个浏览器配置登录 LinkedIn |
| 同事的账号出现在你的 IP 上 | 浏览器配置连同代理设置被复制了 | 一人一个配置、一条 IP，逐个查出口 |
| 某天突然打不开 | IP 到期了 | 提前续费，或打开自动续费 |
| `407 Proxy Authentication Required` | 扩展里的代理账号或密码填错 | 从控制台重新复制 |
| SOCKS5 的 IP 在 Chrome 里打不开网页 | Chrome 不支持带密码的 SOCKS5 | 浏览器用 HTTP 的 IP |

## 常见问答

**账号被 LinkedIn 限制了，换个 IP 有用吗？**
没用。按 LinkedIn 通知里给的步骤如实处理，解除限制和网络地址无关。

**LinkedIn 要我验证身份，代理能代替吗？**
不能。用你本人的信息完成验证，这里没有任何办法能代替它。

**能不能开好几个 LinkedIn 资料页，每个配一条 IP？**
不能。用户协议规定一人一个账号，分开的 IP 改变不了这一点。

**IP 的国家要和资料页上写的一致吗？**
选你实际工作的国家。如果已经搬到别的国家，去改资料页，而不是挑一个和旧地址对得上的 IP。

**有免费试用吗？**
没有。最便宜的测试办法是买 1 天静态 ISP IP，0.50 美元。
